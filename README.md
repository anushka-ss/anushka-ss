## 🚀 Featured Projects

### 📈 [Customer Churn Analysis](https://github.com/anushka-ss/Customer-Churn-Analysis)
A data analytics project that digs into customer behavior patterns to predict churn risk and surface the key factors driving customers to leave — the kind of insight a business can act on directly to improve retention.
**Tech:** Python • Pandas • Data Analytics

### 🔥 [Databricks Students ETL Pipeline](https://github.com/anushka-ss/databricks-students-etl-pipeline)
An end-to-end ETL pipeline built on Databricks that ingests, cleans, and transforms raw student performance data using PySpark, making it ready for downstream analysis and reporting.
**Tech:** Databricks • PySpark • ETL

### 📊 [PySpark Linear Regression](https://github.com/anushka-ss/PySpark-Linear-Regression)
A regression model built entirely with PySpark's MLlib on Databricks, demonstrating distributed machine learning on larger-than-memory datasets.
**Tech:** PySpark • MLlib • Databricks

A healthcare-focused web application project exploring how technology can streamline patient and care-management workflows.
**Tech:** JavaScript
